# Arina Bakyt — Personal Portfolio

Live site: **Add your GitHub Pages URL here after publishing.**

This is Arina Bakyt's personal portfolio website, created for SIS Assignment 1 using HTML5, CSS3, and vanilla JavaScript. It introduces me, presents selected project work, and includes a contact form with client-side validation. The contact form is a demonstration only and does not send or store messages.

## Three design decisions

1. **Navy and white colour palette:** I chose navy blue for emphasis because it feels professional and pairs well with a clean white background.
2. **Responsive project cards:** The project grid changes from three columns on wide screens to fewer columns on smaller screens so the content remains readable.
3. **Accessible interactions:** I added visible keyboard focus styles, labels connected to form inputs, specific validation messages, and a theme toggle for the whole page.
